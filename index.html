2. OBJETIVO

Validar as regras de controle de acesso e visualização de Business Plans (BPs) no BP Web integrados com o sistema HOT. O objetivo principal é garantir a restrição de dados sensíveis apenas aos usuários corretos (envolvidos na demanda no HOT e grupos estratégicos corporativos), prevenindo vazamento de informações e assegurando a rastreabilidade e autoria das demandas.

3. ESCOPO

Dentro do Escopo

  • Gestão de Acessos: Exibição do próprio usuário logado e permissões associadas.
  • Grupos Especiais: Acesso de leitura a todos os BPs para Planejamento, Financeiro e SPE.
  • Vínculo HOT: Visualização do BP correspondente por envolvidos na demanda HOT via link.
  • Bloqueio de Acesso: Restrição de leitura a usuários não envolvidos/não autorizados.
  • Edição de Permissões: Inclusão e exclusão manual de acesso a colaboradores.

5. CASOS DE TESTE

CV-ACC-001/CT-ACC-001 - Visualização do Próprio Usuário na Aba de Gestão de Acessos

Objetivo

Validar que o usuário que está visualizando ou editando um BP consiga ver seu próprio cadastro e nível de permissão listados na aba "Gestão de Acessos".

Pré-condições

  • Usuário logado ao BP Web.

Passos para reproduzir

  1. Acessar o BP Web.
  2. Clicar na aba Gestão de Acessos
  3. Procurar o próprio nome/usuário na lista de acessos.

Resultado Esperado

  • A aba Gestão de Acessos é aberta com sucesso.
  • O próprio usuário é listado de forma clara, indicando o tipo de perfil dele (ex: Elaborador, Gestor, SPE, etc.) e suas permissões (Ativo).

Evidência do Teste (Print da Tela)

Clique para anexar, arraste uma imagem/PDF ou cole do clipboard (Ctrl+V)

CV-ACC-002/CT-ACC-002 - Visualização de todos os BPs por Grupos Especiais (Planejamento, Financeiro, SPE)

Objetivo

Garantir que usuários pertencentes aos grupos Planejamento, Financeiro ou SPE consigam listar, pesquisar e visualizar os detalhes de qualquer BP cadastrado na base, mesmo que não sejam os criadores ou envolvidos diretos.

Pré-condições

  • Usuário cadastrado no sistema BP Web vinculado a pelo menos um dos seguintes grupos: Planejamento, Financeiro ou SPE.
  • Existência de BPs cadastrados na base por outros usuários e setores sem relacionamento com o usuário de teste.

Passos para reproduzir

  1. Acessar o sistema BP Web em homologação.
  2. Logar com o perfil de usuário do grupo de teste (ex: Planejamento).
  3. Navegar até a tela de listagem de Business Plans.
  4. Tentar localizar e abrir um BP criado por um usuário.

Resultado Esperado

  • O sistema exibe todos os BPs na tabela principal para visualização dos grupos especiais.
  • O usuário consegue abrir e visualizar todos os dados do BP de terceiros sem bloqueios.

Evidência do Teste (Print da Tela)

Clique para anexar, arraste uma imagem/PDF ou cole do clipboard (Ctrl+V)

CV-ACC-003/CT-ACC-003 - Visualização de BP via Link HOT por Usuário Envolvido

Objetivo

Garantir que um usuário que esteja cadastrado como envolvido em uma demanda no HOT consiga acessar e visualizar os detalhes do BP correspondente ao clicar no link do HOT.

Pré-condições

  • Demanda de projeto criada no HOT contendo o link do BP Web correspondente.
  • Usuário logado e Envolvido da referida demanda.

Passos para reproduzir

  1. Acessar a demanda de projeto pelo sistema HOT.
  2. Certificar-se que seu usuário está listado como "Envolvido" naquela demanda.
  3. Localizar o link que redireciona para o BP vinculado no BP Web.
  4. Clicar no link HOT.
  5. Verificar se o BP Web abre e exibe a visualização da tela com sucesso.

Resultado Esperado

  • O link HOT redireciona o usuário para o BP Web com o contexto correto.
  • O BP Web valida que o usuário é um envolvido direto e abre o BP para leitura sem bloqueios de segurança.

Evidência do Teste (Print da Tela)

Clique para anexar, arraste uma imagem/PDF ou cole do clipboard (Ctrl+V)

CV-ACC-004/CT-ACC-004 - Bloqueio de Visualização via Link HOT para Usuário NÃO Envolvido

Objetivo

Garantir a segurança dos dados validando que um usuário que NÃO esteja cadastrado como envolvido na demanda HOT e NÃO pertença aos grupos Planejamento, Financeiro ou SPE seja impedido de visualizar o BP ao tentar acessar via link direto.

Pré-condições

  • Link direto do BP Web copiado.
  • Usuário de teste logado que NÃO esteja cadastrado como envolvido naquela demanda e NÃO pertença a nenhum dos 3 grupos especiais.

Passos para reproduzir

  1. Copiar o link de visualização de um BP privado.
  2. Efetuar login no BP Web com a conta do usuário não autorizado.
  3. Colar a URL do link direto do BP na barra de endereços do navegador e pressionar Enter.
  4. Verificar se o sistema impede o acesso.

Resultado Esperado

  • O sistema identifica que o usuário não possui direito de acesso ao BP.
  • O acesso é negado exibindo mensagem de erro (ex: "403 Acesso Negado" ou "Você não possui permissão para visualizar este BP") ou redirecionando para a página inicial com segurança.
